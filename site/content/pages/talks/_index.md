## [Nerdearla 2025] Open Source para empresas: soluciones reales a problemas reales

Esta charla explora el uso de soluciones de código abierto (Open Source) en empresas y PyMEs. El objetivo principal no es solo la reducción de costos, sino fomentar la soberanía de datos y la transparencia mediante herramientas que permiten a las organizaciones mantener el control de su propia infraestructura.

## [Linux Foundation Open Source Summit LATAM 2022] Pinguino Project: Like Arduino, but for PICs

Este vídeo presenta el Proyecto Pinguino, una plataforma de desarrollo electrónico open-source y multiplataforma diseñada para ser accesible, especialmente en el ámbito educativo. Se explica que el proyecto permite crear prototipos electrónicos rápidos utilizando microcontroladores PIC de Microchip.

## [FLISOL 2018] El Software Libre en las PyMES

La charla "El software libre en las PyMEs" se desarrolló en la [UTN Avellaneda](https://flisol.info/FLISOL2018/Argentina/Avellaneda). Explica cómo diversas herramientas de código abierto pueden resolver desafíos tecnológicos específicos en la gestión de cobranzas. En ella se detallan soluciones para CRM, telefonía, correo electrónico y seguridad perimetral, destacando beneficios como el ahorro de costos, la escalabilidad y la soberanía tecnológica. Además, aborda la importancia de usar GNU/Linux en puestos de trabajo, la automatización de procesos con Ansible y la modernización de la infraestructura mediante el monitoreo con Grafana y la conteinarización con Docker.
